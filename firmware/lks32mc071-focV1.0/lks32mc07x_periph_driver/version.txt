 (tag: v3.14) 一、核心改动概述
1. 芯片适配与文件重构
文件更名与替换：
hal_lks32mc05x.c/h 更正为 hal_lks32mc07x.c/h（主文件入口）。
新增 hal_lks32mc07x_reg.h：重新定义 LKS32MC07x 的寄存器结构体（SYS、FLASH、ADC 等），适配新芯片的寄存器地址和位定义。
源文件目录 source/ 新增 LKS32MC07x 专属驱动（如 hal_lks32mc07x_adc.c、hal_lks32mc07x_qep.c 等），覆盖所有外设。
库文件更新：
hal_lksmcu_lib.lib（Keil）和 libhal_lksmcu_lib.a（GCC）替换为适配 07x 芯片的静态库，包含校准参数读取等底层功能。
2. 功能扩展与接口优化
（1）统一中断接口
新增中断函数别名定义（如 HAL_TIMER_IRQHandler_00 = TIMER0_IRQHandler），支持多模块 / 多通道中断，且简化写法（如 HAL_TIMER_IRQHandler 默认指向通道 0）。
明确不支持的中断函数（如 HAL_UART_IRQHandler_20），避免编译错误。
（2）外设功能增强
ADC 新增 GPIO 输入配置（HAL_ADC_SetGpioIn）、触发输出配置；支持温度传感器 / DAC 输入通道细分。
GPIO 新增功能复用枚举（HAL_GPIO_AFx），支持 ADC、QEP、CAN 等外设的 GPIO 映射；优化模式配置逻辑。
MCPWM 扩展输出端口到 6 通道（HAL_MCPWM_PORT_0~5）；新增故障信号配置（HAL_MCPWM_FAIL_x）。
SPI 支持主从模式、CPOL/CPHA 配置、16 位数据宽度；新增 GPIO 引脚指定（CS/MOSI/MISO/CLK）。
UART 支持 3 个 UART 模块；新增校验错误、停止位错误中断；明确 GPIO_TX/RX 配置接口。
QEP 支持正交编码 / 符号脉冲 / 双脉冲模式；新增 GPIO 引脚配置。
FLASH 新增安全参数存储（HAL_FLASH_SecurityParameterSave）、多字节读取（ReadUint8/16/32）。
TRIM 新增芯片 ID 读取（HAL_TRIM_ReadId）和 CRC 校验（HAL_TRIM_ReadIdCrc32）。
（3）修复 bug
修正 HAL_ADC_IrqSamp2Enable 等中断函数的位操作错误。
修复 HAL_DMA_SpiRxTx 接口参数错误（新增接收缓冲区指针，支持全双工通信）。
修正 HAL_WAKE 模块函数名拼写错误（DeepSleepIoWeak → DeepSleepIoWake）。
（4）新增基础功能
芯片默认时钟定义（HAL_INIT_DEFAULE_MCLK = 96MHz），简化时钟配置。
电源初始化接口（HAL_INIT_PowerReady），支持 3.3V/5V 供电配置。
寄存器操作宏扩展（HAL_REG_WRITE_BIT_MASK_POS），简化位域操作。
二、关键文件说明
1. 主文件入口
hal_lks32mc07x.h：
包含所有外设头文件（hal_lksmcu_adc.h、hal_lksmcu_mcpwm.h 等）。
统一中断接口定义、芯片默认参数（时钟、电源）。
必须在用户代码中包含（#include "hal_lks32mc07x.h"）。
hal_lks32mc07x.c：
包含所有外设驱动的入口，通过 #include 引入 source/ 下的具体实现文件。
无需修改，直接添加到工程即可。
2. 寄存器定义文件
hal_lks32mc07x_reg.h：
重新定义了所有外设的寄存器结构体（如 HAL_SYS_TypeDef、HAL_ADC_TypeDef），适配 LKS32MC07x 的寄存器地址和位域。
例：HAL_SYS_TypeDef 新增 DAC_CTRL、CLK_DIV1 等寄存器，对应 07x 芯片的新增功能。
3. 静态库文件
hal_lksmcu_lib.lib（Keil）/ libhal_lksmcu_lib.a（GCC）：
包含校准参数读取（HAL_TRIM_Read）、芯片 ID 校验等底层功能，不可修改。
工程中必须链接该库，否则会导致部分功能（如 ADC 校准、温度传感器读取）异常。
