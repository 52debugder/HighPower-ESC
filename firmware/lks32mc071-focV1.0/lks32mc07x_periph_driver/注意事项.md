# MCPWM 初始化函数配置问题说明

## 问题描述

在以下两个 MCPWM 初始化函数中：
```c
void MCPWM_CH345_Init(MCPWM_InitTypeDef *MCPWM_InitStruct)
void MCPWM_Init(MCPWM_InitTypeDef *MCPWM_InitStruct)
```

新增了 `MCPWM0_AUEN = MCPWM_InitStruct->AUEN;` 的配置项后，发现部分工程中对 `MCPWM_InitStruct->AUEN` 的配置值不正确，导致电机运行异常。

## 解决方案

如果遇到电机运行异常的情况，可以将 `AUEN` 参数配置为该寄存器的默认值：**0x073F073F**。

## 建议操作

1. **检查配置值**：
   - 确认所有工程中 `MCPWM_InitStruct->AUEN` 的配置是否正确
   - 特别注意新增加的 `AUEN` 参数配置

2. **默认值恢复**：
   - 当出现电机运行异常时，可将 `AUEN` 配置为默认值 `0x073F073F`
   - 示例代码：
     ```c
     MCPWM_InitStruct->AUEN = 0x073F073F;  // 使用默认值
     ```

3. **验证影响**：
   - 修改配置后测试电机运行状态
   - 确认异常是否解决
