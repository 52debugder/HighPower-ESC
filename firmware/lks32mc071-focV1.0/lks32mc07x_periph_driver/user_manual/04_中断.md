# 中断

嵌套向量中断控制器位于CPU核内部。当中断事件发生时，通知CPU暂停主程序执行，按照优先级设定跳转进入中断服务函数。

LKS32MC07x系列芯片共有25个外部中断源。

中断控制器最多支持4个中断优先级可供编程选择。
